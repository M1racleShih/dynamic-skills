<p align="center"><strong>dynamic-skills</strong></p>
<p align="center">A versioned skill pool. Just the skills your project needs.</p>

Dynamic Skills keeps Agent Skills in a central, versioned pool and distributes an
explicit selection to each project. Built for Codex, Claude Code, Kimi Code and Pi.

> The first release is under development. See the command help for available operations.

## Development

Requires Python 3.11+ and Git for repository sources.

```sh
uv sync --group dev
uv run pytest
uv run dskills --help
```
